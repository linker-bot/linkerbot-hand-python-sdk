## Joint Order

The SDK reads and sets joint data in the following order.

| Position | `joint_names` | Joint |
| ---: | --- | --- |
| 1 | `thumb_flex` | Thumb flexion |
| 2 | `thumb_abd` | Thumb abduction |
| 3 | `index` | Index finger |
| 4 | `middle` | Middle finger |
| 5 | `ring` | Ring finger |
| 6 | `pinky` | Little finger |

<a id="identity"></a>

## Device Identity

`get_device_info()` actively reads device identity information.

```python
# 主动读取设备身份信息
info = hand.get_device_info(timeout=1.0)
# 查看设备身份信息
print(info)
```

<a id="capabilities"></a>

## Device Capabilities

`get_capabilities()` returns basic capability information for the current model. It does not send control commands.

```python
capabilities = hand.get_capabilities()

# View all capability information
print(capabilities)
```

<a id="angle-control"></a>

## Angle Control

### Reading Angles

`get_angles()` reads the current angles once and returns the following fields:

- `raw`: raw angle values returned by the device, ranging from 0 to 255. Smaller values mean more flexion; larger values mean more extension.
- `percent`: converted angle percentages, ranging from 0 to 100. Smaller values are closer to closed; larger values are closer to open.


```python
sample = hand.get_angles(timeout=1.0)  # 读取一次，最多等待 1 秒
print(sample.raw)  # 原始角度值
print(sample.percent)  # 角度百分比
```

### Setting Raw Angles

`set_angles()` accepts 6 raw angle values in `joint_names` order.

```python
# 按 joint_names 顺序设置角度
print(hand.set_angles([128] * 6).wait(timeout=1.0))
# 回读当前角度，核对真机姿态
print(hand.get_angles(timeout=1.0).raw)
```

### Setting Percentage Angles

`set_percent_angles()` accepts 6 angle percentages from 0 to 100. For flexion joints, 0 is the flexed endpoint and 100 is the extended endpoint.

```python
# 按 joint_names 顺序设置百分比角度
print(hand.set_percent_angles([50] * 6).wait(timeout=1.0))
```

<a id="speed-control"></a>

## Speed Control

Speed settings control the movement speed of each joint.

### Reading Configured Speeds

`get_configured_speeds()` actively reads the current speed settings.

```python
# 读取当前速度设置
print(hand.get_configured_speeds(timeout=1.0).raw)
```

### Setting Speeds

`set_speeds()` sets a speed value from 0 to 255 for each joint.

```python
# 设置各关节速度
print(hand.set_speeds([100] * 6).wait(timeout=1.0))
```

<a id="acceleration"></a>

## Setting Acceleration

Acceleration settings control how quickly each joint's movement speed changes.

### Reading Configured Accelerations

`get_configured_accelerations()` actively reads the current acceleration settings.

```python
# 读取当前加速度
print(hand.get_configured_accelerations(timeout=1.0).raw)
```

### Setting Acceleration

`set_accelerations()` sets an acceleration value from 0 to 254 for each joint. Writing 0 selects the device-defined maximum acceleration.

```python
# 设置各关节加速度
print(hand.set_accelerations([100] * 6).wait(timeout=1.0))
```

<a id="sensor-reading"></a>

## Reading Sensor Data

### Reading Currents

`get_currents()` actively reads the current of each joint. `raw` contains the raw current values from the device protocol.

```python
# 读取各关节当前电流原始值
print(hand.get_currents(timeout=1.0).raw)
```

### Reading Temperatures

`get_temperatures()` reads joint temperatures in degrees Celsius (°C).

```python
# 读取各关节温度
print(hand.get_temperatures(timeout=1.0).raw)
```

### Reading Tactile Arrays

`get_force("fn")` reads the 10×4 tactile array of each of the five fingertips. `fn` denotes the normal tactile array. `force.tactile` preserves its two-dimensional layout, while `force.fn.raw` stores the same device-returned values.

A field of `None` means no data is available. In `valid_values`, `True` marks a valid value and `False` marks an invalid value.

```python
# 读取指定触觉数据，不对点阵求和
force = hand.get_force("fn", timeout=1.0)
print(force.fn.raw if force.fn is not None else None)
```
