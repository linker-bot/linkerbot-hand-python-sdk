## Joint Order

The SDK reads and sets joint data in the following order.

| Position | `joint_names` | Joint |
| ---: | --- | --- |
| 1 | `thumb_flex` | Thumb flexion |
| 2 | `thumb_abd` | Thumb abduction |
| 3 | `index` | Index finger |
| 4 | `middle` | Middle finger |
| 5 | `ring` | Ring finger |
| 6 | `pinky` | Little finger |

<a id="identity"></a>

## Device Identity

`get_device_info()` actively reads device identity information.

```python
# 主动读取设备身份信息
info = hand.get_device_info(timeout=1.0)
# 查看设备身份信息
print(info)
```

<a id="capabilities"></a>

## Device Capabilities

`get_capabilities()` returns basic capability information for the current model. It does not send control commands.

```python
capabilities = hand.get_capabilities()

# View all capability information
print(capabilities)
```

<a id="angle-control"></a>

## Angle Control

### Reading Angles

`get_angles()` reads the current angles once and returns the following fields:

- `raw`: raw angle values returned by the device, ranging from 0 to 255. Smaller values mean more flexion; larger values mean more extension.
- `percent`: converted angle percentages, ranging from 0 to 100. Smaller values are closer to closed; larger values are closer to open.

```python
sample = hand.get_angles(timeout=1.0)  # 读取一次，最多等待 1 秒
print(sample.raw)  # 原始角度值
print(sample.percent)  # 角度百分比
```

### Setting Raw Angles

`set_angles()` accepts 6 raw angle values. This example uses `[128] * 6`; adjust the actual target for the device parameters and mechanical conditions.

```python
# 读取力矩，确认当前处于位置模式
if any(hand.get_torques(timeout=1.0).raw):
    raise RuntimeError("L6 当前有力矩模式关节；请先切回位置模式")
# 发送 6 个原始角度值，等待通信结果
print(hand.set_angles([128] * 6).wait(timeout=1.0))
# 回读当前角度，核对真机姿态
print(hand.get_angles(timeout=1.0).raw)
```

### Setting Percentage Angles

`set_percent_angles()` accepts 6 values in `0..100`. For flexion axes, 0 typically means flexed and 100 means extended.

```python
# 读取力矩，确认当前处于位置模式
if any(hand.get_torques(timeout=1.0).raw):
    raise RuntimeError("L6 当前有力矩模式关节；请先切回位置模式")
# 发送 6 个百分比角度，等待通信结果
print(hand.set_percent_angles([50] * 6).wait(timeout=1.0))
```

<a id="speed-control"></a>

## Speed Control

Speed settings control each joint's movement speed. Larger values produce faster movement.

### Setting Speeds

`set_speeds()` sets a speed value from 0 to 255 for each joint. After writing, use `get_configured_speeds()` to read the values in the device's response.

```python
# 将 6 个关节速度设为 100
print(hand.set_speeds([100] * 6).wait(timeout=1.0))
```

### Reading Configured Speeds

`get_configured_speeds()` reads the device's response to speed settings in the current connection. Run the speed-setting command above first.

```python
# 读取设备返回的速度设置
print(hand.get_configured_speeds(timeout=1.0).raw)
```

<a id="torque-control"></a>

## Torque Control

`set_torques()` writes a value to each joint to select its control mode:

| Written value | Control mode | Behavior |
| --- | --- | --- |
| `0` | Position mode | Angle commands control finger pose |
| `1` to `255` | Torque mode | Sets the joint's protocol torque value (not measured torque); angle commands cannot control joint movement in this mode |

> **Control note:** Switching back to position mode does not automatically send an angle target.

### Setting Position Mode

Write `0` to all 6 joints. To change the target pose, send another angle target after the mode switch succeeds.

```python
# 向 6 个关节写入 0，切回位置模式；运动需另设目标角度
print(hand.set_torques([0] * 6).wait(timeout=1.0))
```

### Setting Torque Output

The protocol torque value specifies the output level in torque mode. Larger values produce stronger joint output. The example writes `10` to all 6 joints; adjust it for your device and task.

```python
# 向 6 个关节写入协议值 10，切入力矩模式；按任务调整
print(hand.set_torques([10] * 6).wait(timeout=1.0))
```

### Reading Protocol Torque Values

`get_torques()` actively reads the protocol values currently returned by the device. `0` means position mode; a nonzero value means torque mode and specifies its protocol torque value.

```python
# 读取协议值，确认模式和出力设置
print(hand.get_torques(timeout=1.0).raw)
```

<a id="sensor-reading"></a>

## Reading Sensor Data

### Reading Currents

`get_currents()` actively reads the current of each joint. `raw` contains the raw current values from the device protocol.

```python
# 读取各关节当前电流原始值
print(hand.get_currents(timeout=1.0).raw)
```

### Reading Temperatures

`get_temperatures()` reads joint temperatures in degrees Celsius (°C).

```python
# 读取各关节温度
print(hand.get_temperatures(timeout=1.0).raw)
```

### Reading Tactile Arrays

`get_force("fn")` reads the normal tactile arrays of all five fingertips. `force.fn.raw` stores the raw values returned by the device.

A field of `None` means no data is available. In `valid_values`, `True` marks a valid value and `False` marks an invalid value.

```python
# 读取指定触觉数据，不对点阵求和
force = hand.get_force("fn", timeout=1.0)
print(force.fn.raw if force.fn is not None else None)
```
