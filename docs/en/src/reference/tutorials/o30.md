## Joint Order

The SDK reads and sets joint data in the following order.

| Position | `joint_names` | Joint |
| ---: | --- | --- |
| 1 | `thumb_rotation` | Thumb rotation |
| 2 | `thumb_roll` | Thumb roll |
| 3 | `index_abd` | Index finger abduction |
| 4 | `middle_abd` | Middle finger abduction |
| 5 | `ring_abd` | Ring finger abduction |
| 6 | `pinky_abd` | Little finger abduction |
| 7 | `thumb_root1` | First thumb root joint |
| 8 | `index_root1` | First index finger root joint |
| 9 | `middle_root1` | First middle finger root joint |
| 10 | `ring_root1` | First ring finger root joint |
| 11 | `pinky_root1` | First little finger root joint |
| 12 | `index_root2` | Second index finger root joint |
| 13 | `middle_root2` | Second middle finger root joint |
| 14 | `ring_root2` | Second ring finger root joint |
| 15 | `pinky_root2` | Second little finger root joint |
| 16 | `thumb_tip` | Thumb tip |
| 17 | `index_tip` | Index finger tip |
| 18 | `middle_tip` | Middle finger tip |
| 19 | `ring_tip` | Ring finger tip |
| 20 | `pinky_tip` | Little finger tip |

<a id="angle-control"></a>

## Angle Control

### Reading Angles

`get_angles()` reads the current angles once and returns the following fields:

- `raw`: raw angle values returned by the device, ranging from 0 to 255. Larger values mean more flexion; smaller values mean more extension.
- `percent`: converted angle percentages, ranging from 0 to 100. Smaller values are closer to closed; larger values are closer to open.


```python
sample = hand.get_angles(timeout=1.0)  # 读取一次，最多等待 1 秒
print(sample.raw)  # 原始角度值
print(sample.percent)  # 角度百分比
```

### Setting Raw Angles

`set_angles()` accepts 20 raw angle values in `joint_names` order.

```python
# 按 joint_names 顺序设置角度
print(hand.set_angles([128] * 20).wait(timeout=1.0))
# 回读当前角度，核对真机姿态
print(hand.get_angles(timeout=1.0).raw)
```

### Setting Percentage Angles

`set_percent_angles()` accepts 20 angle percentages from 0 to 100. For flexion joints, 0 is the flexed endpoint and 100 is the extended endpoint.

```python
# 按 joint_names 顺序设置百分比角度
print(hand.set_percent_angles([50] * 20).wait(timeout=1.0))
```

`get_temperatures()` reads joint temperatures. `raw` contains the raw temperature values from the device protocol.

```python
# 读取各关节温度

```

### Reading Tactile Data

O30 tactile fields and the number of values per finger depend on the actual sensors; they are not fixed two-dimensional arrays.

| Field | Meaning |
| --- | --- |
| `fn` | Normal tactile data |
| `fns` | Per-finger normal summary |
| `ft` | Tangential tactile data |
| `fts` | Per-finger tangential summary |
| `fd` | Tangential direction data |
| `fds` | Per-finger tangential direction summary |
| `px` | Proximity sensor data |

`get_force()` requests `fn` and `fns` by default and also returns other fields provided by the sensors in the same sample. If the sensors do not provide these two fields, use a call such as `get_force("ft", timeout=1.0)` to request a supported field.

Each field's `raw` stores raw values per finger. `valid_values` marks whether each value is valid. A field or finger value of `None` means no data was provided. Direction and proximity data retain raw values from the device protocol.

```python
# 读取一次触觉数据，查看各字段
force = hand.get_force(timeout=1.0)
# Inspect this sample’s tactile fields
for name in ("fn", "fns", "ft", "fts", "fd", "fds", "px"):
    # Get the named field; unavailable fields return None
    field = force.field(name)
    if field is None:
        continue  # 跳过未提供的字段
    # Print the field name and raw values
    print(name, field.raw)
    print("有效值标记", field.valid_values)
```

### Reading Normal Resultant Forces for Five Fingers

`get_normal_force_resultant()` reads the normal summary `fns` for each of the five fingertips. If the device does not provide all five values, the SDK raises an error. It does not fill missing values with 0 or sum the tactile array.

```python
# O30 每指读取一个 FnS，缺失不补零
sample = hand.get_normal_force_resultant(timeout=1.0)
print(sample.sensor_names, sample.raw, sample.units)
```

### Reading Voltages


## Torque Limits

This section covers joint torque readings and torque limit settings.

### Reading Torques

`get_torques()` reads joint torques. `raw` contains the raw torque values from the device protocol.

```python
# 读取各关节力矩原始值
print(hand.get_torques(timeout=1.0).raw)
```

### Torque Limits

Torque limits restrict each joint's torque output. They are independent of current limits.

#### Reading Torque Limits

`get_torques_limits()` actively reads the current torque limits.

```python
# 读取当前力矩限制
print(hand.get_torques_limits(timeout=1.0).raw)
```

#### Setting Torque Limits

`set_torques_limits()` sets a torque limit from 0 to 255 for each joint.

```python
# 设置各关节力矩限制
print(hand.set_torques_limits([100] * 20).wait(timeout=1.0))
```
