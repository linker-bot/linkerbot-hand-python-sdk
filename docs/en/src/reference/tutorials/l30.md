## Joint Order

The SDK reads and sets joint data in the following order.

| Position | `joint_names` | Joint |
| ---: | --- | --- |
| 1 | `thumb_root` | Thumb root |
| 2 | `thumb_tip` | Thumb tip |
| 3 | `thumb_abd` | Thumb abduction |
| 4 | `thumb_rotation` | Thumb rotation |
| 5 | `ring_abd` | Ring finger abduction |
| 6 | `ring_tip` | Ring finger tip |
| 7 | `ring_root` | Ring finger root |
| 8 | `middle_root` | Middle finger root |
| 9 | `middle_tip` | Middle finger tip |
| 10 | `pinky_root` | Little finger root |
| 11 | `pinky_tip` | Little finger tip |
| 12 | `pinky_abd` | Little finger abduction |
| 13 | `middle_abd` | Middle finger abduction |
| 14 | `index_abd` | Index finger abduction |
| 15 | `index_root` | Index finger root |
| 16 | `index_tip` | Index finger tip |
| 17 | `wrist` | Wrist |

## Device Identity

`get_device_info()` actively reads device identity information.

```python
# 主动读取设备身份信息
info = hand.get_device_info(timeout=1.0)
# 查看设备身份信息
print(info)
```

<a id="capabilities"></a>

## Device Capabilities

`get_capabilities()` returns basic capability information for the current model. It does not send control commands.

```python
capabilities = hand.get_capabilities()

# View all capability information
print(capabilities)
```

<a id="enable-disable"></a>

## Enabling and Disabling

Enabling and disabling control whether the device accepts movement commands.

### Enable

`enable()` turns on normal drive output for L30.

```python
# Send the enable command
print(hand.enable().wait(timeout=5.0))
```

### Disable

`disable()` turns off normal drive output for L30. After the call, the device may no longer hold its current pose.

```python
# Send the disable command
print(hand.disable().wait(timeout=5.0))
```

<a id="angle-control"></a>

## Angle Control

### Reading Angles

`get_angles()` reads the current angles once and returns the following fields:

- `raw`: raw angle values returned by the device. Ranges vary by joint. Larger values mean more flexion; smaller values mean more extension.
- `percent`: converted angle percentages, ranging from 0 to 100. Smaller values are closer to closed; larger values are closer to open.


```python
sample = hand.get_angles(timeout=1.0)  # 读取一次，最多等待 1 秒
print(sample.raw)  # 原始角度值
print(sample.percent)  # 角度百分比
```

### Setting Raw Angles

`set_angles()` accepts 17 raw angle values in `joint_names` order.

```python
# 按 joint_names 顺序设置角度
print(hand.set_angles([0] * 17).wait(timeout=1.0))
# 回读当前角度，核对真机姿态
print(hand.get_angles(timeout=1.0).raw)
```

### Setting Percentage Angles

`set_percent_angles()` accepts 17 angle percentages from 0 to 100. For flexion joints, 0 is the flexed endpoint and 100 is the extended endpoint.

```python
# 按 joint_names 顺序设置百分比角度
print(hand.set_percent_angles([50] * 17).wait(timeout=1.0))
```

<a id="speed-control"></a>

## Speed Control

### Reading Current Speeds

`get_speeds()` reads the current speed of each joint.

```python
# 读取各关节当前速度原始值
print(hand.get_speeds(timeout=1.0).raw)
```

Speed settings control the movement speed of each joint.

### Setting Speeds

`set_speeds()` sets a speed value from 1 to 250 for each joint. After writing, `get_configured_speeds()` returns the most recently sent settings in the current connection.

```python
# 设置各关节速度
print(hand.set_speeds([100] * 17).wait(timeout=1.0))
```

<a id="sensor-reading"></a>

## Reading Sensor Data

### Reading Currents

`get_currents()` actively reads the current of each joint. `raw` contains the raw current values from the device protocol.

```python
# 读取各关节当前电流原始值
print(hand.get_currents(timeout=1.0).raw)
```

### Reading Temperatures

`get_temperatures()` reads joint temperatures in degrees Celsius (°C).

```python
# 读取各关节温度
print(hand.get_temperatures(timeout=1.0).raw)
```

### Reading Tactile Arrays

`get_force("fn")` reads the 12×6 tactile array of each of the five fingertips. `fn` denotes the normal tactile array. `force.tactile` preserves its two-dimensional layout, while `force.fn.raw` stores the same device-returned values.

`raw` contains the raw tactile values returned by the device. A field of `None` means no data is available. In `valid_values`, `True` marks a valid value and `False` marks an invalid value.

```python
# 读取指定触觉数据，不对点阵求和
force = hand.get_force("fn", timeout=1.0)
print(force.fn.raw if force.fn is not None else None)
```

<a id="calibration"></a>

## Device Calibration

`calibrate()` stops normal control, unlocks the device, and starts calibration. Position the mechanism as required by the device before running it. The SDK does not automatically re-enable the device after calibration.

```python
# 人工确认设备状态后执行维护操作
if input("确认标定？输入 yes 执行：") != "yes":
    raise SystemExit("未执行")
# 开始标定；该操作会改变设备状态
print(hand.calibrate().wait(timeout=5.0))
```
