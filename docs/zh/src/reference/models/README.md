# 型号协议能力

本目录按型号维护 SDK 已实现接口、协议对象、原始编码、物理单位、比例、响应语义、固件证据和已知限制。新增或修正型号协议时，必须同时更新对应型号文档；总览只提供导航，不替代运行时 capability。

当前已逐项核对：

- [L6](./l6.md)
- [L6 固件支持证据](./l6-firmware-support.md)
- [O6](./o6.md)
- [O6 固件支持证据](./o6-firmware-support.md)

待逐项核对：L20Lite、L20、O20、L30、O30i。未核对型号仍以
`hand.get_capabilities()` 和现有总览为准，不从其他型号类推单位或帧语义。

文档中的“协议支持”表示最新资料定义了该功能；旧固件是否实现由运行时探测决定。SDK 不以固件版本号拒绝连接。可选查询在当前连接代连续 3 次超时或返回结构错误时，SDK 将该单一通道标记为固件不支持、停止继续查询并保留连接；任一次成功读取会清零连续失败计数，重新连接后重新探测。
