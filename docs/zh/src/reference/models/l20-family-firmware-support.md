# L20 / L20Lite 固件支持证据

版本号用于记录证据，不用于拒绝旧手。单台设备的结果不能推断所有更高版本必然支持。
接口、单位与未实现对象分别见 [L20](./l20.md) 和 [L20Lite](./l20lite.md)。

SDK 现已实现 L20Lite 类别查询 `20..23`，依次映射为 `fns/fts/fds/px`。上表是既有
4.6.10 实机的探测记录，不是 SDK 的功能禁用清单，也不是最低固件版本限制。
新增类别各自按可选查询策略判定支持情况，未响应类别不会使其他类别断连。
| 当前限制 | 每指矩阵后多一帧 `Bx FF 00 00`，不属于矩阵 | 0.5 ms 向量间隔可遗漏回复；1 ms 的独立对照 240/240 完整 |

连接与恢复均成功；查询返回 `DEVICE_RESPONSE`，角度写反馈为
`DEVICE_COMMAND_FEEDBACK`。所有数值核对以线上原值为准，未按名称假定物理比例。

## 并发短窗口

每组约 6 秒，100 Hz 提交固定当前角度，请求 100 Hz 角度反馈及 30 Hz 五指矩阵。
下列为停止轮询前的运行时 achieved Hz；力矩阵另逐样本与独立抓包核对。

| 型号 / 策略 | 角度 Hz | 五指触觉 Hz | 角度/触觉超时次数 |
| --- | ---: | ---: | --- |
| L20 / QUERY_ONLY | 97.99 | 29.00 | 1 / 0 |
| L20 / COMMAND_FEEDBACK_ONLY | 100.00 | 30.00 | 0 / 0 |
| L20 / ADAPTIVE | 100.00 | 30.00 | 0 / 0 |
| L20Lite / QUERY_ONLY | 91.84 | 25.00 | 0 / 1 |
| L20Lite / COMMAND_FEEDBACK_ONLY | 96.33 | 28.83 | 0 / 1 |
| L20Lite / ADAPTIVE | 81.50 | 24.17 | 0 / 5 |

L20Lite 缺失行在独立原始接收器中同样缺失；没有发布不完整的触觉样本，连接保持，
角度最新目标按既有 latest-wins 策略可替代排队旧值。降低触觉到 20 Hz 的同类测试仍有
缺行，不能仅以降低请求频率宣称修好。所有场次结束时查询角度等于该场起始目标，故障为零。
进一步绕过 Hand SDK，使用原始 SocketCAN 逐指查询、每指后停留 2 ms，500 次中仍有 2 次
缺行（独立接收器也缺同一行）。尚需交换适配器或设备端抓帧才能区分固件与链路原因。

这是短时特定负载的结果，不是 Hz 上限或长期零丢帧保证。触觉矩阵本次未施加已知载荷，
不能验证牛顿比例、受压定位或有变化数据下的物理同步性。

## 不支持与未测试

实时速度、温度、触觉在当前连接尚未成功时，连续三次超时/结构错误触发单通道
`UnsupportedFirmwareError` 并停止后续查询。成功过的通道不因后续丢帧误降级；恢复/重连
清除判定。该行为用故障注入测试验证；本次两台实机均支持三类查询，没有冒充旧固件实测。
身份与角度、故障、负载仍需完成基线初始化。

速度/负载的物理换算、触觉受压标定、清错的真实故障恢复、右手、其他固件和持久管理
命令仍未验证。协议资料里其他产品分支的“某版本以上支持”不能直接移植到这两个产品号。
