| 索引编号 | 关节名称 | 关节 |

| 5 | `ring_abd` | 无名指侧摆 |
| 6 | `pinky_abd` | 小指侧摆 |
| 7 | `thumb_root1` | 拇指根部第一关节 |
| 8 | `index_root1` | 食指根部第一关节 |
| 9 | `middle_root1` | 中指根部第一关节 |
| 10 | `ring_root1` | 无名指根部第一关节 |
| 11 | `pinky_root1` | 小指根部第一关节 |

<a id="angle-control"></a>

## 角度控制

### 角度读取

`get_angles()` 读取一次当前角度，返回以下字段：

- `raw`：设备返回的原始角度值，范围为 0～255，数值越大越弯曲，越小越伸直。
- `percent`：换算后的角度百分比，范围为 0～100，数值越小越接近闭合，越大越接近张开。


```python
sample = hand.get_angles(timeout=1.0)  # 读取一次，最多等待 1 秒
print(sample.raw)  # 原始角度值
print(sample.percent)  # 角度百分比
```

### 原始角度设置

`set_angles()` 接收 20 个原始角度值，顺序见 `joint_names`。

```python
# 按 joint_names 顺序设置角度
print(hand.set_angles([128] * 20).wait(timeout=1.0))
# 回读当前角度，核对真机姿态
print(hand.get_angles(timeout=1.0).raw)
```

### 百分比角度设置

`set_percent_angles()` 接收 20 个 0 到 100 的百分比角度。屈伸关节中，0 表示弯曲端，100 表示伸直端。

```python
# 按 joint_names 顺序设置百分比角度
print(hand.set_percent_angles([50] * 20).wait(timeout=1.0))
```

## 传感器数据读取

### 电流读取

`get_currents()` 主动读取各关节当前电流，`raw` 保存设备协议中的电流原始值。

```python
# 读取各关节当前电流原始值

```

### 温度读取

`get_temperatures()` 读取各关节温度，`raw` 保存设备协议中的温度原始值。

```python
# 读取各关节温度
print(hand.get_temperatures(timeout=1.0).raw)
```

### 触觉读取

O30 的触觉字段和每指数据数量由实际传感器决定，不固定为二维点阵。

| 字段 | 含义 |
| --- | --- |
| `fn` | 法向触觉数据 |
| `fns` | 每指法向汇总值 |
| `ft` | 切向触觉数据 |
| `fts` | 每指切向汇总值 |
| `fd` | 切向方向数据 |
| `fds` | 每指切向方向汇总值 |
| `px` | 接近传感器数据 |

`get_force()` 默认请求 `fn` 和 `fns`，并返回同一次采样中传感器提供的其他字段。传感器不提供这两项时，可改用 `get_force("ft", timeout=1.0)` 等调用，请求其支持的字段。

各字段的 `raw` 按手指保存原始数值；`valid_values` 标记对应数值是否有效。字段或某指数据为 `None` 表示未提供数据。方向和接近数据保留设备协议中的原始值。

```python
# 读取一次触觉数据，查看各字段
force = hand.get_force(timeout=1.0)
# 逐项检查本次触觉字段
for name in ("fn", "fns", "ft", "fts", "fd", "fds", "px"):
    # 按字段名取值；未提供时返回 None
    field = force.field(name)
    if field is None:
        continue  # 跳过未提供的字段
    # 输出字段名和原始值
    print(name, field.raw)
    print("有效值标记", field.valid_values)
```

### 五指法向合力读取

`get_normal_force_resultant()` 读取五个指尖各自的法向汇总值 `fns`。若设备没有完整提供五个值，SDK 会报错，不会用 0 补齐，也不会对触觉点阵求和。

```python
# O30 每指读取一个 FnS，缺失不补零
sample = hand.get_normal_force_resultant(timeout=1.0)
print(sample.sensor_names, sample.raw, sample.units)
```
