## 经典 CAN 连接与测试

设备和适配器须已配置为经典 CAN，且波特率一致。以下为右手、默认请求 ID `0x001`、1 Mbit/s 的完整只读示例：

```python
from linkerbot_hand import DeviceConfig, HandDevice, TransportKind
from linkerbot_transport.can import CANTransport

hand = HandDevice(
    model="O30",
    side="right",
    transport=CANTransport("can0"),
    config=DeviceConfig(hop_transport=TransportKind.CAN, hop_request_id=0x001),
)
try:
    hand.open()
    print(hand.get_device_info(timeout=2.0))
    print(hand.get_angles(timeout=2.0).raw)
finally:
    hand.close()
```

`hop_transport` 只选择 SDK 的帧格式，不修改设备模式或主机接口。经典 CAN 禁用 BRS；CAN FD 继续使用原来的 FD transport，并省略 `hop_transport` 或设为 `TransportKind.CAN_FD`。左手默认请求 ID 为 `0x002`，自定义 ID 使用实际值；回复 ID 为请求 ID `| 0x400`。无侧别信息的固件，发现结果保留 `PARTIAL`，需显式指定侧别后构造。

在仓库根目录运行测试脚本（使用已安装本次源码的 Python 环境）：

```bash
# 默认只读：身份、15 项状态/配置、触觉、轮询、重新打开和恢复
python examples/o30_classic_can.py --channel can0 --side right

# 回写原有配置并回读；只修改一个关节的原目标，随后恢复原目标
python examples/o30_classic_can.py --channel can0 --side right --write-back --motion-joint 6 --delta 2

# 仅查询，以 50 Hz 请求角度轮询，保存结果及原始帧
python examples/o30_classic_can.py --channel can0 --side right --angles-hz 50 --duration 5 --report o30_can_report.json
```

`--motion-joint` 是从 0 开始的关节索引，`--delta` 是原始角度变化量（非零，-5～5）。默认不发送运动指令；`--write-back` 只回写原有配置，不发送角度指令。运动测试读取真实目标寄存器，保留其他关节原目标，结束或异常时恢复原目标并回读核对。脚本不修改 CAN ID、波特率或模式，不保存 Flash，也不切回 CAN FD。默认请求 ID 随 `--side` 选择；非默认设备用 `--request-id 0x123` 指定。

经典 CAN 每帧最多承载 5 字节对象数据。SDK 将长范围读取和整手 25 槽写入拆成每段最多 5 字节的请求，收到当前段回复后再查询或写入下一段；读取收齐后才更新完整状态。任一段失败就停止，已执行的写入段无法回滚。CAN FD 保持原来的读取方式。整手控制和返回状态不是同一时刻的采样；命令确认也不代表机械到位。轮询频率是请求目标，实际新样本数量以报告为准。`snapshot` 保存最新完整状态，不是数据队列。

`--motion-timeout 2` 在写入测试目标和恢复原目标后分别持续查询当前角度约 2 秒。脚本严格核对目标寄存器，并记录实际角度、偏差和其他关节的变化；物理原因可能导致实际角度与目标不一致，甚至没有可观测变化，这些观测不作为 SDK 失败条件。`PASS` 表示通信及目标回读通过，不保证机械到位或精度。`--delta` 相对于原目标计算，不能用它保证实际位移大小。协议、通信或目标回读错误返回 `FAIL`、退出码 1。运行测试期间不要让其他程序同时对该端点查询或写入。

`NO_SENSOR` 在报告中标记 `SKIP`；零值保留原值，不判为故障。已遇到固件切换后仍回报旧接口类型的情况，应结合实际 CAN 帧标志确认模式。未保存 Flash 的模式切换可能在断电后恢复原设置。

已验证 O30 与 P7 共用经典 CAN 总线并由两个 SDK 同进程通信、关闭重连；50 Hz 联合轮询仍观察到偶发查询超时和数据过期，暂未增加自动重试，也未确定根因。该结果说明基本通信兼容，不保证持续 50 Hz 无丢失。

其余示例使用已连接的 `hand`，结束后调用 `hand.close()`。

| 8 | `index_root1` | 食指根部第一关节 |

| 10 | `ring_root1` | 无名指根部第一关节 |

## 角度控制

### 角度读取

`get_angles()` 读取一次当前角度，返回以下字段：

- `raw`：设备返回的原始角度值，范围为 0～255，数值越大越弯曲，越小越伸直。
- `percent`：换算后的角度百分比，范围为 0～100，数值越小越接近闭合，越大越接近张开。


```python
sample = hand.get_angles(timeout=1.0)  # 读取一次，最多等待 1 秒
print(sample.raw)  # 原始角度值
print(sample.percent)  # 角度百分比
```

### 原始角度设置

`set_angles()` 接收 20 个原始角度值，顺序见 `joint_names`。

```python
# 按 joint_names 顺序设置角度
print(hand.set_angles([128] * 20).wait(timeout=1.0))
# 回读当前角度，核对真机姿态
print(hand.get_angles(timeout=1.0).raw)
```

### 百分比角度设置

`set_percent_angles()` 接收 20 个 0 到 100 的百分比角度。屈伸关节中，0 表示弯曲端，100 表示伸直端。

```python
# 按 joint_names 顺序设置百分比角度
print(hand.set_percent_angles([50] * 20).wait(timeout=1.0))
```

## 传感器数据读取

### 电流读取

```python
# 读取各关节当前电流原始值

```

### 温度读取

`get_temperatures()` 读取各关节温度，`raw` 保存设备协议中的温度原始值。

```python
# 读取各关节温度
print(hand.get_temperatures(timeout=1.0).raw)
```

### 触觉读取

O30 的触觉字段和每指数据数量由实际传感器决定，不固定为二维点阵。

| 字段 | 含义 |
| --- | --- |
| `fn` | 法向触觉数据 |
| `fns` | 每指法向汇总值 |
| `ft` | 切向触觉数据 |
| `fts` | 每指切向汇总值 |
| `fd` | 切向方向数据 |
| `fds` | 每指切向方向汇总值 |
| `px` | 接近传感器数据 |

`get_force()` 默认请求 `fn` 和 `fns`，并返回同一次采样中传感器提供的其他字段。传感器不提供这两项时，可改用 `get_force("ft", timeout=1.0)` 等调用，请求其支持的字段。

各字段的 `raw` 按手指保存原始数值；`valid_values` 标记对应数值是否有效。字段或某指数据为 `None` 表示未提供数据。方向和接近数据保留设备协议中的原始值。

```python
# 读取一次触觉数据，查看各字段
force = hand.get_force(timeout=1.0)
# 逐项检查本次触觉字段
for name in ("fn", "fns", "ft", "fts", "fd", "fds", "px"):
    # 按字段名取值；未提供时返回 None
    field = force.field(name)
    if field is None:
        continue  # 跳过未提供的字段
    # 输出字段名和原始值
    print(name, field.raw)
    print("有效值标记", field.valid_values)
```

### 五指法向合力读取

`get_normal_force_resultant()` 读取五个指尖各自的法向汇总值 `fns`。若设备没有完整提供五个值，SDK 会报错，不会用 0 补齐，也不会对触觉点阵求和。

```python
# O30 每指读取一个 FnS，缺失不补零
sample = hand.get_normal_force_resultant(timeout=1.0)
print(sample.sensor_names, sample.raw, sample.units)
```

### 电压读取

`get_voltages()` 读取各关节电压，`raw` 保存设备协议中的电压原始值。

```python
# 读取各关节电压原始值
print(hand.get_voltages(timeout=1.0).raw)
```
