## 关节顺序

SDK 按以下顺序读取和设置关节数据。

| 索引编号 | 关节名称 | 关节 |
| ---: | --- | --- |
| 1 | `thumb_flex` | 拇指弯曲 |
| 2 | `thumb_abd` | 拇指侧摆 |
| 3 | `index` | 食指 |
| 4 | `middle` | 中指 |
| 5 | `ring` | 无名指 |
| 6 | `pinky` | 小指 |

## 身份识别

`get_device_info()` 主动读取设备身份信息。

```python
# 主动读取设备身份信息
info = hand.get_device_info(timeout=1.0)
# 查看设备身份信息
print(info)
```

<a id="capabilities"></a>

## 能力查询

`get_capabilities()` 查询当前型号的基本能力信息。此方法不发送控制命令。

```python
capabilities = hand.get_capabilities()
# 查看全部能力信息
print(capabilities)
```

<a id="angle-control"></a>

## 角度控制

### 角度读取

`get_angles()` 读取一次当前角度，返回以下字段：

- `raw`：设备返回的原始角度值，范围为 0～255，数值越小越弯曲，越大越伸直。
- `percent`：换算后的角度百分比，范围为 0～100，数值越小越接近闭合，越大越接近张开。

```python
sample = hand.get_angles(timeout=1.0)  # 读取一次，最多等待 1 秒
print(sample.raw)  # 原始角度值
print(sample.percent)  # 角度百分比
```

### 原始角度设置

`set_angles()` 接收 6 个原始角度值。示例使用 `[128] * 6`，实际目标请按设备参数和机械条件调整。

```python
# 读取力矩，确认当前处于位置模式
if any(hand.get_torques(timeout=1.0).raw):
    raise RuntimeError("L6 当前有力矩模式关节；请先切回位置模式")
# 发送 6 个原始角度值，等待通信结果
print(hand.set_angles([128] * 6).wait(timeout=1.0))
# 回读当前角度，核对真机姿态
print(hand.get_angles(timeout=1.0).raw)
```

### 百分比角度设置

`set_percent_angles()` 接收 6 个 `0..100` 数值。屈伸轴通常为 0=弯曲、100=伸直。

```python
# 读取力矩，确认当前处于位置模式
if any(hand.get_torques(timeout=1.0).raw):
    raise RuntimeError("L6 当前有力矩模式关节；请先切回位置模式")
# 发送 6 个百分比角度，等待通信结果
print(hand.set_percent_angles([50] * 6).wait(timeout=1.0))
```

<a id="speed-control"></a>

## 速度控制

速度设置用于控制各关节的运动速度，数值越大，运动越快。

### 速度设置

`set_speeds()` 为每个关节设置速度值，范围为 0 到 255。写入后可用 `get_configured_speeds()` 读取设备回复的值。

```python
# 将 6 个关节速度设为 100
print(hand.set_speeds([100] * 6).wait(timeout=1.0))
```

### 速度配置读取

`get_configured_speeds()` 读取本次连接中速度设置的设备回复；请先执行上面的速度设置命令。

```python
# 读取设备返回的速度设置
print(hand.get_configured_speeds(timeout=1.0).raw)
```

<a id="torque-control"></a>

## 力矩控制

`set_torques()` 给每个关节写入一个值，用这个值选择控制模式：

| 写入值 | 控制模式 | 能做什么 |
| --- | --- | --- |
| `0` | 位置模式 | 用角度命令控制手指姿态 |
| `1` 到 `255` | 力矩模式 | 设置该关节的力矩协议值（非实测力矩）；此时无法发送角度指令控制关节运动 |

> **控制提示**：切回位置模式时，不会自动发送角度目标。

### 位置模式设置

给 6 个关节写入 `0`，如需改变当前关节目标姿态，请在模式切换成功后，再次设置角度目标。

```python
# 向 6 个关节写入 0，切回位置模式；运动需另设目标角度
print(hand.set_torques([0] * 6).wait(timeout=1.0))
```

### 力矩输出设置

力矩协议值表示力矩模式的输出等级：数值越大，关节输出越强。下面为 6 个关节写入协议值 `10`，请按设备与任务调整。

```python
# 向 6 个关节写入协议值 10，切入力矩模式；按任务调整
print(hand.set_torques([10] * 6).wait(timeout=1.0))
```

### 力矩协议值读取

`get_torques()` 主动读取设备当前返回的协议值：`0` 表示位置模式，非零表示力矩模式及其力矩协议值。

```python
# 读取协议值，确认模式和出力设置
print(hand.get_torques(timeout=1.0).raw)
```

<a id="sensor-reading"></a>

## 传感器数据读取

### 电流读取

`get_currents()` 主动读取各关节当前电流，`raw` 保存设备协议中的电流原始值。

```python
# 读取各关节当前电流原始值
print(hand.get_currents(timeout=1.0).raw)
```

### 温度读取

`get_temperatures()` 读取各关节温度，单位为摄氏度（℃）。

```python
# 读取各关节温度
print(hand.get_temperatures(timeout=1.0).raw)
```

### 触觉点阵读取

`get_force("fn")` 读取五个指尖的法向触觉点阵，`force.fn.raw` 保存设备返回的原始值。

字段为 `None` 表示没有数据；`valid_values` 中的 `True` 表示对应数值有效，`False` 表示无效。

```python
# 读取指定触觉数据，不对点阵求和
force = hand.get_force("fn", timeout=1.0)
print(force.fn.raw if force.fn is not None else None)
```
